# Jev 在提名后、强化调研前审阅候选

Discovery 先采集材料并提名，提名阶段不调用 Jev。CLI 采集并做基础去重，Agent 合并事件、命名并绑定证据；随后 CLI 在候选主题审阅时调用 Jev，识别垃圾信息并按多个维度评价研究价值，供 Agent 选择值得进入强化调研的候选。这把模型判断集中在调研资源分配之前，避免为所有原始采集条目引入模型调用；具体评分标准另行确定。

该决定替换讨论中的“采集后逐条初筛、补证后再次评分”两阶段 Jev 方案。首版不据此增加强化调研后的第二个常规 Jev 阶段；最终判断与综合继续由 Agent 负责。

第八轮明确此候选审阅要求适用于 Discovery：不可主动跳过 Jev，不可用时允许明确记录的降级。用户指定的 Named-Topic 直接进入主题研究，不经过提名与候选审阅，不属于绕过 Discovery 审阅；详见 [研究能力](../design/research-capabilities.md)。
