# Jev + 浏览器采集兜底探索

阅读入口：[MVP 规格](mvp-spec.md) · [文档索引](../README.md)。本文保留专题细节与历史提案；当前范围以主规格及后续有效决定为准。

状态：2026-09-28 第十八轮探索记录；第十九轮 Q60 已决定 MVP 不实现浏览器兜底，仅使用 Brave 兜底。本页保留为后续参考，以下建议不属于 MVP 待实现范围。仅核查官方文档及组织仓库 main 页面，未安装依赖、运行浏览器实验或调用付费模型；示例不构成七渠道的可用性验收。

## 可行性结论

技术上可行，已有 Jev 与浏览器组合的公开示例。建议定位为有限目标的页面采集补充：Agent 给出目标链接和证据缺口，CLI 负责渲染、必要交互、保存原文和校验，Jev 可辅助选择有限动作。通用网页探索与登录态采集不应从本次探索请求中推定为已接受需求。

TypeSafe 示例中的网页采集与其合成航班页面是两个不同预设；不能把沙盒交互验证当成真实网站采集验证。两个项目的计量和终止参数均不是 Siglens 已确认默认值。

Jev 接受文本与 JSON 状态，不支持直接理解截图。因此应提供 DOM 文本、元素及已取得材料，而非只传网页截图。来源：[TypeSafe State](https://docs.typesafe.ai/concepts/state)。

## Browser Use 的使用层次

本地库可以通过 Browser / BrowserSession 直接打开页面和读取 DOM，无需创建自主 Agent；按提示词寻找元素或语义提取内容的方法则需要模型。其 Actor 文档位于 legacy 路径，实现前需固定版本验证接口，不能假定所有文档示例跨版本可用。来源：[浏览器参数](https://docs.browser-use.com/open-source/customize/browser/all-parameters)、[Actor API](https://docs.browser-use.com/open-source/legacy/actor/all-parameters)。

本地库、云浏览器和云 Agent 是不同产品组合。建议先评估本地库加浏览器运行时，避免在尚未确认的方案中附带云服务和第二个控制模型。来源：[产品区别](https://docs.browser-use.com/cloud/which-product)、[本地安装](https://docs.browser-use.com/open-source/quickstart)。

## 建议的调用路径，待决定

1. 专用渠道或 Brave 提供候选链接，普通页面抓取先尝试取得正文。
2. 原文不足且值得补证时，Skill 指导 Agent 指定目标 URL、所需字段、成功条件和本次执行边界，调用 CLI 浏览器采集能力。
3. CLI 先渲染并使用固定逻辑提取文本；不需要交互时，无需 Jev。
4. 必要时向 Jev 提供观察到的文本、编号元素和有限读取动作，例如等待、滚动、展开正文、翻页；由 CLI 校验目标仍存在且动作允许后执行。
5. 程序从页面复制实际取得的文本，记录结果和缺失；Jev 的完成判断不代替正文与来源校验。Agent 根据证据缺口决定是否继续研究。

这是建议顺序，不要求全部 API 失败后才能补正文，也不保证 Brave 已索引所有内容。没有链接、站点受限或页面不支持时，仍可以返回缺失结果。研究 CLI 不因此承担 Agent 分配或外部工作流调度。

## 证据与动作边界建议

证据继续遵守 [渠道与证据契约](source-evidence-contract.md)：正文和实际引用片段分开，保留原始及最终 URL、取得时间、材料类型和完整程度。浏览器渲染文本应明确检索方式；同一材料由 HTTP 和浏览器分别取得，不构成两个独立来源。

Jev 可选择正文块或有限动作，正文由程序从已观察材料中取得，不由模型生成。仅取得搜索片段、摘要、登录提示或错误页时如实记录；不要把页面打开成功当成取得目标证据，也不要把模型判断当成事实已确认。

建议使用独立临时浏览器环境，并只开放明确的采集动作。域名限制只限制导航，不能单独保证动作只读；任意点击、输入和执行脚本不应自动成为可用能力。已观察元素标识、页面状态检查和结束条件应由执行器验证。

## 与既有 Jev 和预算规则的关系（历史探索）

第二十轮进一步移除了 MVP 额度控制。本节保留探索时的背景，不构成当前要求；未来若重启浏览器方向，资源策略需重新评估。

本方案的页面状态 / 动作判断，是候选资格与研究价值审阅之外的新用途，需要单独记录调用目的。尚未变更“提名不调用 Jev”的既有阶段规则：如果希望在提名采集中也启用浏览器 Jev，须明确这是采集辅助的例外，而非默认引入。

若采纳，CLI 产生的浏览器辅助 Jev 费用应进入同一研究的 Jev 费用累计；本地浏览器并不意味着模型调用免费。金额未知时应记录未知，不能用零代替。

一次导航或浏览器动作会触发多个网络请求，不能把动作数等同于 Q43 的实际数据请求数。Q56 的免费外部 CLI 内部请求例外不自动适用于 Python 浏览器库；目标文档 / 数据接口请求与图片、字体等子资源的计量边界仍待决定。浏览器页数、动作数、时长限制可作为额外执行边界，具体值待验证。

## 后续验证建议

采纳范围后再做小规模实验，比较普通 HTTP、仅浏览器渲染、浏览器加 Jev 的正文取得率、原文准确性、时间和费用。样例应覆盖动态正文、展开 / 翻页、时间缺失、目标内容不存在和访问失败；同时检查中断后已取得材料仍可交付。无需直接复制演示项目的步数、置信度或终止阈值。
