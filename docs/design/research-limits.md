## 当前范围

- MVP 不设采集次数上限或 Jev 费用上限，不提供默认额度、预算配置、额度预留、耗尽停机或增加额度后恢复。
- Q61–Q63 随本次范围调整撤回；免费外部 CLI 的额度例外也无需单独实现。
- 允许付费接入。调用次数、服务返回的用量及错误可作为诊断信息，不作为研究执行门槛；不为额度管理建设精确计费账本，不将未知用量伪造为零。
- 保留阶段性结果。同一研究内默认复用相同操作的已有结果，Agent 明确要求刷新时重新请求。第二十六轮 Q71 已确认续跑时复用成功结果，只继续失败或未完成的操作。
- Skill 指导 Agent 根据证据缺口决定继续，由 Agent 判断研究问题是否已充分回答。CLI 执行结构化计划，不自行发起无边界研究循环。
- 最终主题卡默认上限仍为天数 × 3；这是交付数量要求，未被此次资源额度撤回影响。
- 外部服务限流、故障或账户不可用仍按既有失败与降级规则记录，不伪装为健康空结果。取消额度控制不改变真实服务错误的处理。

## 同一研究的可变状态

同一研究的 CLI 状态变更串行执行，Agent 可以并行分析材料。不同研究相互独立；这不要求单次 CLI 内所有网络请求也串行。

建议并行分析引用明确的材料版本，提交时校验所基于的版本，避免较早的判断覆盖较新结果。冲突时返回可处理的信息，由 Skill 指导 Agent 重新读取或调整；版本格式与拒绝 / 等待策略尚未确定。

同机可通过局部互斥保护文件；跨机器交接由 Skill 指导外部工作流按串行要求安排，本地锁不能防止不同机器上的独立副本同时写入。CLI 不因此新增跨机器运输或调度服务。

## 后续待设计

- 相同操作的身份、成功结果复用规则、材料版本及刷新提示。
- 失败和异常中断后的具体重试机制、阶段性产物状态；续跑成功复用原则已由 Q71 确认。
- 状态提交冲突的处理，以及可观测错误和调用诊断的最小字段。

这些是数据正确性与可恢复执行问题，不再依赖预算或额度机制。

## 同一研究的时间窗口

Q78 已确认：创建研究时将“最近 N 天”解析并保存为固定起止时间。续跑、补证和显式刷新均继续使用该窗口；采集时间可以更新，但窗口不随当前时刻自动滑动。需要“截至现在的最近 N 天”时建立新研究。

此方案使操作复用、事件时间校验和交付范围保持一致，避免中断一天后静默改变研究对象范围。窗口外背景材料仍按既有规则允许引用；默认七天的产品决定不因此改变。起止边界、时区和材料查询覆盖需在具体契约中明确，不声称外部列表能还原任意历史时刻。窗口固定政策已确认，具体时间表示在接口设计中落实。
