## 上游实际规则

核查固定提交 `084662b501fb0dba95bd55eff0c258d35e0dc499`，避免把注释中的旧 LLM 流程当成实际调用链。

- 初始提名已有 velocity <= 0 的过滤和数量截断；协议最多 15 个提名，强化调研最多 6 个。因此不能说补证前完全没有门槛，也不能把最终上限 10 理解为一定有 10 个主题。
- host 明确标为 junk 的提名不进入强化调研；没有 host junk 判断时才回退启发式，启发式 junk 少于两个 seed source 时跳过。显式非 junk 可以覆盖启发式。
- worthiness 为 0–100，用于 `velocity × (0.5 + worthiness / 100)` 排序，没有单独的低 worthiness 硬淘汰线；缺失值按 50 使用。排序后再截取强化调研名额。
- 补证后要求至少一项材料且互动总数不少于 25，普通候选还需至少两个 source 或互动总数不少于 200。启发式 junk 不适用单 source 高互动豁免，其两个 source 依据初始 seed 计算。
- 最终还有数量截断、同事件合并和热度排序。因此未出现于最终结果可能是资格、门槛、截断或重复，不能统一解释为研究价值低。

初筛和名额位置：`pipeline.py:904–918,975,1316–1320,1769–1771`。补证失败或空结果可回用 seed 证据计算门槛（`1066–1116`），并不自动删除；前 6 个之后不合格也没有从剩余候选自动补位的循环。Siglens 不移植这些固定 15 / 6 名额。

## Siglens 建议规则

| 检查 | 建议处理 | 与现有决定的关系 |
| --- | --- | --- |
| 纯猜测、领域无关、缺乏具体新事项的垃圾信息 | 排除；保留原因和材料引用 | 纯猜测与 junk 排除已确认；语义判断由 Jev 辅助、Agent 最终确认 |
| 重复事件 | 合并并保留证据关联 | Agent 合并事件已确认；不记作低价值淘汰 |
| 事件明确发生于窗口外且没有窗口内新进展 | 不进入最终近期卡；有用材料可作背景 | 已确认按事件 / 实质进展时间判断 |
| 初始证据不足或事件时间未知 | 保留待核查，Agent 决定补证 | 不因无法判断而自动判成低价值；事件时间补证后仍未知则不计入最终近期卡 |
| 四维 Score 均成功返回并通过响应校验，分数全部低于中点 3 | 标记低价值淘汰建议，交 Agent 确认是否不进入强化调研 | Q68 已采纳；按 1–5 映射后的连续分数判断，不能用 Jev 原始 0–4 分数直接比较 3 |
| 最终交付前 | 核查事件时间、支持陈述的证据、跨渠道核查尝试和必需字段 | 必须尝试跨渠道，不要求两个独立来源；一手材料可单独支持其直接证明的事项 |
| 合格候选超过最终卡片数量上限 | Agent 选择，其余记录本轮未入选 | 不是垃圾或事实被否定，也不保证下轮自动入选 |

表中“全部低于 3”是 Q68 采纳的保守起点，后续通过样例评测调整：四个维度均未达到中等程度才提出低价值淘汰建议。没有按平均分、总分或最高档概率硬淘汰。任一有效维度达到 3 仅表示未触发此建议，不保证有资格、获得补证或最终入选。

实现时应使用未舍入的有效分数比较；在五档映射下，展示分 < 3 等价于 Jev 原始 score < 2。不能把展示用四舍五入后的数字拿来判断，也不能用原始 score < 3。当前仅使用 Score，见 [评分设计](jev-assistance.md)。

不再设置评分 unknown 或可评分性 Choice；证据薄弱或低 confidence 不会自动屏蔽合法 Score。证据不足仍独立记录并交给 Agent 判断，不直接等同低价值。Jev 不可用或某维响应无效时记录执行失败，四维低分条件未满足，按既有规则由 Agent 接手，不能补造评分触发门槛。

低分规则作用于候选审阅阶段，不新增研究后的常规 Jev 评分步骤。Agent 如认为低分建议不适用，可选择继续并写明材料依据；若新材料改变了判断，可提交新的审阅版本。具体重审触发与调用接口仍待设计。

## 不移植的规则

- 不设置最低点赞 / 评论门槛：低互动的一手发布、论文和网页仍可能值得研究。
- 不按 velocity <= 0 删除初始提名：缺少互动指标不能使新事件失去被审阅的机会。
- 不要求两个 source 才能通过：source 种类不等于独立证据，且与一手材料可独立支持事项的决定冲突。
- 不把缺失或失败的模型响应填成最低分或中档；不将合法的模型分数再转换为评分 unknown。
- 不允许高热度或高价值分抵消纯猜测、领域无关或时间不合格。

## 留痕建议与边界样例

候选记录区分排除、待核查、合并、低价值未选和合格但本轮未入选；具体枚举待定。建议保存规则版本、触发条件、Jev 原始结果、有效评分状态、证据引用及 Agent 最终决定；淘汰指不进入后续选择，不删除已取得材料。

- 一手新发布只有一个来源、互动为零：不因这些数字淘汰，尝试跨渠道核查后按证据交付。
- 高互动但只有即将发布的社区猜测：按纯猜测排除，不用总分救回。
- 四维为 2.4 / 2.7 / 2.1 / 2.8：提出低价值淘汰建议，Agent 确认。
- 四维中某维响应缺失或无效：记录执行失败，不触发四维低分建议，交 Agent 按降级规则判断；这不是 unknown 评分。
- 四维为 2.4 / 2.7 / 4.2 / 2.8：不触发全部低于中点条件；是否研究由 Agent 综合决定。
- 四维很高但事件时间始终未知：保留待核查，不进入最终近期卡。

实施前需用包含低互动一手发布、薄证据候选、明确垃圾与临界分数的人工样例检查误淘汰。上游没有可直接搬用的 Jev 五档分数阈值，不能宣称本提案已经验证。
